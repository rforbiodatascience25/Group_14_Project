# Description of Files

All files are end-to-end executable and independent from other qmd files.

01_load: Loading libraries and raw data, ready for further clean up.

02_clean: Tidying by joining two datasets in one and removing necessary NA values.

03_augment: Added variable, temperature in Celsius degrees.

04_data_analysis_1: Data analysis on the different oceans.

05_data_analysis_2: Data analysis focusing ONLY on the Pacific ocean.

00_all: Full project that can run in one GO.

For unknown reasons, 04_data_analysis_1, 05_data_analysis_2 and 00_all were not able to be placed in '/results' as HTML files, without turning blank, despite them being showcased perfectly as HTML files from the 'R' folder.

Therefore, 04_data_analysis_1, 05_data_analysis_2 and 00_all are found as HTML files under Group_14_Project / R.

01_load, 02_clean and 03_augment are found as HTML files under Group_14_Project / results.
